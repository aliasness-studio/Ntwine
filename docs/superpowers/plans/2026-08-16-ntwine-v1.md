# Ntwine v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Ntwine v1 — an Electron sample browser that imports the orphaned Splice
library from `sounds.db`, then lets the owner search/filter/preview samples and drag them
into Reaper.

**Architecture:** Electron main process owns SQLite (better-sqlite3 + FTS5), the import
pipeline, a `utilityProcess` waveform-decode worker, the `sample://`/`cover://` protocols,
and `startDrag`. The React 19 renderer (MobX stores, styled-components, TanStack Virtual)
talks only through one typed preload bridge. Spec: `docs/superpowers/specs/2026-08-16-ntwine-v1-design.md`
(panel-reviewed; treat it as authoritative when this plan is silent).

**Tech Stack:** Electron Forge 7.11.2 (vite-typescript template, Vite 5, CJS main) ·
Electron 43 · TypeScript ~5.9 strict · React 19 · MobX ^6.15 + mobx-react-lite ^4 ·
styled-components ^6 · better-sqlite3 ^13 · audio-decode ^3 · @tanstack/react-virtual ^3 ·
Vitest · yarn.

## Global Constraints

- **TDD every logic task**: failing test → run → minimal code → pass → commit. No exceptions.
- **Repo root** is `<repo>`. All paths below are repo-relative.
- **Pre-audit rule:** before implementing a task, verify its referenced files/symbols exist
  as described; if the template scaffold named something differently, adapt and note it in
  the commit body — do not blind-follow.

- Renderer never touches fs/SQLite; `contextIsolation` on, `webSecurity` on, no
  `nodeIntegration` (spec §4). `sample://`/`cover://` address by **catalog id only**.
- Main process stays **CJS**; Vite stays **5.x**; do not bump (spec §9.1).
- MobX pinned `^6.15`, mobx-react-lite `^4.1` (cross-repo parity — spec §4.1). Not 7.x.

```ts
import { ipcMain, nativeImage, type NativeImage } from 'electron';

export function makeDragIcon(): NativeImage {
  const size = 24;
  const buf = Buffer.alloc(size * size * 4);
  for (let i = 0; i < size * size; i++) buf.set([48, 44, 40, 255], i * 4); // BGRA, must be non-empty on macOS
  return nativeImage.createFromBitmap(buf, { width: size, height: size });
}

export function registerDragHandler(resolvePath: (sampleId: number) => string | null): void {
  const icon = makeDragIcon();
  ipcMain.on('ntwine:drag-start', (event, sampleId: number) => {
    const file = resolvePath(Number(sampleId));
    if (file) event.sender.startDrag({ file, icon });
  });
}
```

```js
// scripts/gen-fixture-audio.mjs — writes 44100 Hz mono 16-bit PCM: sine.wav + sine.aiff
import { mkdirSync, writeFileSync } from 'node:fs';
const RATE = 44100, N = 4410, A = 0.5; // 100 ms
const pcm = new Int16Array(N);
for (let i = 0; i < N; i++) pcm[i] = Math.round(Math.sin((2 * Math.PI * 440 * i) / RATE) * A * 32767);
const pcmBE = Buffer.alloc(N * 2); const pcmLE = Buffer.alloc(N * 2);
for (let i = 0; i < N; i++) { pcmLE.writeInt16LE(pcm[i], i * 2); pcmBE.writeInt16BE(pcm[i], i * 2); }

// WAV (LE)
const wav = Buffer.alloc(44 + pcmLE.length);
wav.write('RIFF', 0); wav.writeUInt32LE(36 + pcmLE.length, 4); wav.write('WAVEfmt ', 8);
wav.writeUInt32LE(16, 16); wav.writeUInt16LE(1, 20); wav.writeUInt16LE(1, 22);
wav.writeUInt32LE(RATE, 24); wav.writeUInt32LE(RATE * 2, 28); wav.writeUInt16LE(2, 32);
wav.writeUInt16LE(16, 34); wav.write('data', 36); wav.writeUInt32LE(pcmLE.length, 40);
pcmLE.copy(wav, 44);

// AIFF (BE). COMM sampleRate is 80-bit extended float; 44100 = 40 0E AC 44 00*6
const ext44100 = Buffer.from([0x40, 0x0e, 0xac, 0x44, 0, 0, 0, 0, 0, 0]);
const comm = Buffer.alloc(26); comm.write('COMM', 0); comm.writeUInt32BE(18, 4);
comm.writeUInt16BE(1, 8); comm.writeUInt32BE(N, 10); comm.writeUInt16BE(16, 14);
ext44100.copy(comm, 16);
const ssnd = Buffer.alloc(16 + pcmBE.length); ssnd.write('SSND', 0);
ssnd.writeUInt32BE(8 + pcmBE.length, 4); pcmBE.copy(ssnd, 16);
const form = Buffer.alloc(12); form.write('FORM', 0);
form.writeUInt32BE(4 + comm.length + ssnd.length, 4); form.write('AIFF', 8);

mkdirSync('tests/fixtures', { recursive: true });
writeFileSync('tests/fixtures/sine.wav', wav);
writeFileSync('tests/fixtures/sine.aiff', Buffer.concat([form, comm, ssnd]));
console.log('fixtures written');
```

```ts
import { readFile } from 'node:fs/promises';
import decode from 'audio-decode';

export interface DecodedAudio { sampleRate: number; channels: Float32Array[] }

export async function decodeAudio(filePath: string): Promise<DecodedAudio> {
  const buf = await readFile(filePath);
  const audio = await decode(buf); // AudioBuffer-shaped: numberOfChannels, sampleRate, getChannelData
  const channels: Float32Array[] = [];
  for (let c = 0; c < audio.numberOfChannels; c++) channels.push(audio.getChannelData(c));
  return { sampleRate: audio.sampleRate, channels };
}
```

```ts
process.parentPort.on('message', async (e) => {

});
```
